Выявлять ошибки, связанные с неактуальными справками (истёк срок «свежести», неверный юр. адрес, КПП и др.).

## REQ-TRAIN-001: Доступ к площадкам для поиска причин отклонения
Дать агенту доступы к площадкам, где размещаются данные заказчиков, для поиска причин отклонения заявок. Безопасность обеспечивается подписанием основных документов ЭП.

## REQ-TRAIN-002: Документы по выигранным процедурам ТЭК СПб
Выдать документы по ТЭК СПб, по которым уже выигрывали процедуры, для просмотра корректности заполнения заявки.

## REQ-TRAIN-003: Косячные заявки по версиям
Выдать косячные заявки (сохранены по версиям), чтобы перепроверить, что найдёт ИИ и что нашли люди.

## REQ-TRAIN-004: Требования 44-ФЗ и 223-ФЗ
Скормить агенту текущие законодательные требования по 44-ФЗ и 223-ФЗ, чтобы он подсвечивал риски несоответствия закона и требований конкурсной документации.
